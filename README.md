# Quiet Ledger — personal finance

Local-first Flutter app to **record**, **track**, **plan** and **project**
personal finances (EUR), replacing an Excel sheet. Runs on Android, iOS, web,
Windows, macOS and Linux. Product plan: [`PLAN.md`](PLAN.md). Code
conventions: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md). Design draft
("Quiet Ledger"): [`docs/design/`](docs/design/).

## Run

```sh
flutter pub get
dart run tool/l10n.dart          # merge lib/l10n/parts/*.arb + gen-l10n
dart run build_runner build      # Drift code (only after schema changes)
flutter run -d linux             # or: chrome, android, windows, macos, ios
```

The database is encrypted with SQLite3MultipleCiphers on native platforms
(key in the OS secure storage) and on the web via the custom drift worker in
`web/` (rebuild it with `tool/build_web_worker.sh` after upgrading drift).

## Check

```sh
dart format --output=none --set-exit-if-changed lib test tool
dart run tool/l10n.dart --check  # fails on missing German strings
dart run tool/version.dart --check   # app_version.dart + CHANGELOG in sync
dart analyze
flutter test                     # unit, DB, widget and app-flow tests
flutter test tool/screenshots/screenshots_test.dart   # PNGs in build/screenshots
```

CI (`.github/workflows/ci.yml`) runs the same checks plus a build matrix for
all six platforms and the integration tests on Linux.

## Versioning

Semantic versioning (`MAJOR.MINOR.PATCH+BUILD`) from `version:` in
`pubspec.yaml`; release notes in [`CHANGELOG.md`](CHANGELOG.md). Policy and
release steps: [`docs/VERSIONING.md`](docs/VERSIONING.md).

```sh
dart run tool/version.dart bump minor   # major | minor | patch | build
git commit -am "Release X.Y.Z" && git tag -a vX.Y.Z -m vX.Y.Z
```

## Layout

| Path | Contents |
|---|---|
| `lib/core/` | Money, Drift schema + `SyncWriter` (HLC + ChangeLog), settings catalogue, ledger repository, recurrence/holidays/budget periods, sync engine, CSV |
| `lib/app/` | Bootstrap, router, adaptive shell, theme tokens, shared widgets |
| `lib/features/` | accounts, categories, transactions, rules, import, export, budgets, recurring, goals, plan, forecast, scenarios, reports, dashboard, settings, security, onboarding |
| `test/fixtures/import/` | Excel/CSV fixtures (generated by `tool/fixtures/`) |

## Known limitations

- Web DB encryption is implemented but not yet verified in a real browser;
  the web key is only as safe as the browser profile.
- Android auto-export to a picked folder may need a Storage Access Framework
  writer under scoped storage.
- Linux cannot schedule notifications (plugin limitation); immediate alerts work.
- Not in v1 (per plan): sync backend, multi-currency, xlsx export, Sankey,
  forecast uncertainty band, `.ods`/`.numbers` import.
